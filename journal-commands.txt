MCP Grocery Assistant Command Journal
Project Root

Most commands should be run from the project root:

cd C:\Users\shann\TafeLocal\rest-at2\grocery-assistant-mcp
Run Tests

Run the test suite:

pytest -q

Use this after making changes to service functions, tools, resources, or prompts.

Run MCP Stdio Server
Option 1: Run stdio server directly

From the project root:

python -m grocery_assistant_mcp.stdio_server
Option 2: Run stdio server through MCP Inspector

From the project root:

npx @modelcontextprotocol/inspector .\.venv\Scripts\python.exe -m grocery_assistant_mcp.stdio_server

This launches MCP Inspector and connects it to the stdio server.

Run MCP Inspector Only

To open MCP Inspector manually:

npx @modelcontextprotocol/inspector

Use this when you want to manually configure the connection inside the Inspector UI.

Run Streamable HTTP Server

From the project root:

python -m grocery_assistant_mcp.streamable_http_server

Expected server URL:

http://127.0.0.1:8000/mcp

A browser request to / may return 404 Not Found, and a browser request to /mcp may return 406 Not Acceptable. This is expected because /mcp expects MCP JSON-RPC requests, not normal browser page requests.

Connect MCP Inspector to HTTP Server

Use these settings in MCP Inspector:

Transport: Streamable HTTP
URL: http://127.0.0.1:8000/mcp

Use this to test resources, tools, and prompts over HTTP.

MCP Session ID

After running the initialize request, copy the returned session ID.

Example:

mcp-session-id: 7ab88075d6744da99d21802e73b6b74a

For easier testing, store it in a PowerShell variable:

$McpSessionId = "7ab88075d6744da99d21802e73b6b74a"
$McpUrl = "http://127.0.0.1:8000/mcp"

Then curl commands can use:

-H "mcp-session-id: $McpSessionId"

This avoids manually replacing the session ID in every command.

Curl: Initialize MCP Session

Request file:

curl_requests/01_initialize.json

Command:

curl.exe -i -X POST $McpUrl `
  -H "Content-Type: application/json" `
  -H "Accept: application/json, text/event-stream" `
  --data-binary "@curl_requests/01_initialize.json"

Purpose:

Starts the MCP handshake and returns an mcp-session-id.

After this succeeds, copy the session ID and set:

$McpSessionId = "PASTE_SESSION_ID_HERE"
