This folder contains the documentation set for the Grocery Assistant MCP Version 1.2 stage.

docs/version_1_2_completion_checklist.md

## Files

### README.md

Main project overview for Version 1.2. Explains the project purpose, current capabilities, data model, resources, tools, testing, and scope boundaries.

### project_roadmap.md

Longer-term staged roadmap from Version 1.0 to Version 1.5.

### version_1_2_completion_checklist.md

Definition of done for closing Version 1.2.

### mcp_testing_guide.md

Manual testing guide for MCP Inspector and curl.

For Version 1.2, MCP Inspector testing was completed and curl testing was deferred as a documentation follow-up.

### command_reference.md

Common PowerShell, pytest, server, MCP Inspector, curl, and git commands.

### development_journal_v1_2.md

Cleaned journal summary for the Version 1.2 development stage.

### future_version_plans.md

Deferred future ideas, including controlled inventory consumption, batch meal logging, shopping support, meal planning intelligence, and waste pattern learning.
